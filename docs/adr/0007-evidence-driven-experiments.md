# 技术研究以证据驱动实验交接，探索上限与证据接收分离

Status: accepted (implementation pending)

既有技术利用路线、带外证据和有界续探允许复杂研究持续进行，但仅凭新的变体名称或未经取证的结论，仍可能造成无效续探或过早停止。决定在既有 planner/worker、事实和工具接口上承载证据驱动实验：技术推理继续用自然语言，执行归属、操作与观察位置、证据引用及执行状态采用最小结构化；续探依据实际实验与可定位观察，结论性停止依据显式观察及相应证据。

同类上限继续约束新增探索投入，但不再仅凭类型计数拒绝接收已经取得、符合收取纪律的独立根因发现；同根因优先补证，独立根因须有依据。此决策明确调整 ADR-0004 配套实现中的上报拒收行为，并澄清 ADR-0006 中类型触顶优先的含义是停止新增投入，不是丢弃已有证据；类型触顶不因新的名称、严重度声明或本决策而自动重开路线。路线预算、任务控制、类型锚定及证据线继续有效。

## Considered Options

- 仅追加专题构造和提示词：不能保证模型取得完整基线、实验确已执行或结论已交回对应路线。
- 每类漏洞增加 agent、专用调度器或第二张路线图：重复既有生命周期与证据逻辑；先加深现有接口，执行增强由可重复的评估失败证明必要性。
- 新增变体字符串即计作信息增量：无法区分计划、实际实验和同一观察的改写。
- 以模型替身或提示词关键词测试证明发现能力提升：只能证明编排或装配；真实模型在隔离材料上的决策效果单独评估。

## Consequences

历史事实和发现保持可读，不伪造实验引用或回填 observed；缺少必要证据的历史结论不获得新增的停止权威，明确的人工停止与预算控制仍生效。知识路由覆盖多类处理过程，但不成为每站必测配额。真实模型评估固定输入、配置与预算，记录失败及成本；其结果只说明相应场景中的行为变化，不外推真实 SRC 出洞率。
